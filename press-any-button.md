# Press Any Button

**II_PressAnyButtonPrompt** reacts to the first button pressed on any device, e.g. for a title screen, to continue after a cutscene or to start a prompt sequence. Mouse movement and small stick movements don’t count.

- **Accept**: **Any Button** (“Press any button”) or **Specific Action** (e.g. “Press \[A\] to start”, with the icon shown by an Image or Text Prompt).

- **Include Mouse Buttons**, **Include Touch**, **Accept After** (so the press that opened the screen doesn’t count) and **Once**.

- **Hide On Press**, an optional blinking text, and the event **On Pressed** with the device that was used.
