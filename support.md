# Licenses and Contact

The labels of the Input Icons sprites (including the Keyboard and Gamepad Sprites Vol 1 and Vol 2) use the font **Inter** (Inter 18pt SemiBold) by The Inter Project Authors. Inter is licensed under the SIL Open Font License 1.1 and is free to use, also in commercial projects. The license text is included in the package (Inter_OFL.txt), see also the file Third-Party Notices.txt.

The font files themselves are not included. You only need Inter if you want to edit the .svg source files of the sprites. They are in zip files (e.g. “…\_Sources.zip”), so Unity doesn’t import them: unzip them outside of your Assets folder. Install Inter first, otherwise your graphics program shows the labels in a different font. Download: <https://rsms.me/inter> or <https://fonts.google.com/specimen/Inter>
