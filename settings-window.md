# Input Icons Settings Window

All settings of the Input Icons Manager are also available in the Input Icons Settings window (Tools → Input Icons → Input Icons Settings, or the “Settings Window” button on the manager). It organizes them in categories:

- **General:** Input Action Assets and control schemes

- **Devices:** start device, gamepad priority, switching delay, stick deadzone, cursor, joysticks and Steam

- **Text & Style Tags:** display type, automatic style sheet updates, delimiters, opening and closing tags, animated texts, text display language and the Text Prompt tags

- **Action Names:** names shown for actions in texts

- **Rebinding** and **Player Profiles:** rebind behaviour, saving rebound bindings and player profiles

- **Assets:** where sprite and font assets are created, fonts, texture compression and mipmaps

- **Debug:** logging and shortcuts to the other windows

The window always edits the active Input Icons Manager and supports undo and redo, like the inspector.
