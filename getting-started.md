# Getting Started

The easiest way to set up Input Icons is the setup wizard. Open it from the toolbar: **Tools → Input Icons → Input Icons Setup Wizard**. The setup takes about a minute: Input Icons detects most settings in your project, you confirm them, choose a look and press one button.
