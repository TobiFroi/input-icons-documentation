# UI Toolkit

There is an [**extension asset**](https://assetstore.unity.com/packages/tools/gui/input-icons-ui-toolkit-extension-255994) available which allows you to display Input Icons in UI Toolkit. That extension is available for free on the asset store as a separate package. (Some features like advanced mode for prompts, displaying input icons as fonts or displaying bindings for local multiplayer games is currently not possible in the UI Builder extension and would require additional work)
