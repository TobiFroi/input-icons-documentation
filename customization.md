# Customization

Input Icons works out of the box, but most of it can be adjusted: the sprites and icon sets, how bindings are displayed, memory and performance settings, and how the icons update.

Most settings are in the **Input Icons Settings** window (Tools → Input Icons → Input Icons Settings). The pages below explain them in detail.
