# Input Icons for Input System

Input Icons shows the current bindings of your Input System actions as icons: in SpriteRenderers, UI Images, TextMesh Pro texts and UI Toolkit. When the player switches between keyboard and mouse and a gamepad, or rebinds a key, every prompt updates by itself.

[Get Started](/input-icons-documentation/getting-started){: .btn .btn-primary .fs-5 .mb-4 .mb-md-0 .mr-2 }
[Input Icons on the Asset Store](https://assetstore.unity.com/packages/tools/gui/input-icons-for-input-system-213736){: .btn .fs-5 .mb-4 .mb-md-0 }

## Features

- **Prompts for every kind of UI:** Sprite Prompts, Image Prompts and Text Prompts, TextMesh Pro style tags like `<style=Player/Jump>`, and UI Toolkit (with the UI Toolkit extension).
- **Keyboard, mouse and gamepads:** sprites for keyboard and mouse, Xbox, PlayStation and Nintendo controllers are included, plus mobile and Steam Input support.
- **Animated prompts:** icons can alternate between the normal and the pressed sprite of a key.
- **Interaction prompts:** Tap, Hold, Mash and Timing prompts, interactables, quick time events and combos, tutorial hints, button hint bars and "Press any button".
- **Rebinding:** ready-made rebind buttons, saving and loading, player profiles and local multiplayer.
- **Setup wizard:** sets up your Input Action Assets, control schemes, icon sets and texts in a few steps, and checks your project for problems.

## Requirements

- **Input System** 1.2.0 or higher (1.6.3 or higher recommended)
- **TextMesh Pro** 2.1.6 or higher (included in Unity 6 and newer)
- **2D Sprite** 1.0.0 or higher, only needed to create the sprite assets for TextMesh Pro

The Welcome page of the setup wizard checks these requirements and can import or install what is missing.
